# Карточка модели: название и версия

- **Задача:** что предсказывает (например, «падает / не падает» по окну 2 с)
- **Вход и выход:** форма тензора, классы
- **Обучение:** данные (набор, сколько клипов, кто в кадре), гиперпараметры, коммит, запуск MLflow
- **Качество на наборе eval:** вывод `scripts/eval_gate.py` (полнота, ложные тревоги, задержка)
- **Где ошибается:** известные провалы — сидение на пол, наклон, частичное перекрытие
- **Ограничения и этика:** только скелеты, без лиц; не медицинское изделие
