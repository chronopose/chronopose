# Карточка модели: классификатор действий v0

- **Задача:** по окну скелета 2 с (шаг 0,5 с) определить «стоит / идёт / падает / лежит». Движку событий нужна p(падает).
- **Вход:** 8 признаков позы в длинах туловища (`src/models/preprocess.py`): угол туловища в конце окна и его изменение, разброс угла, падение плеч, скорость падения плеч, горизонтальная скорость бёдер, соотношение сторон рамки, покрытие окна кадрами.
- **Варианты:**
  - `RuleClassifier` — правила с сигмоидами, по умолчанию. Без обучения, объясним на защите.
  - `ForestClassifier` — Random Forest, 200 деревьев, глубина до 10, сбалансированные веса (`python scripts/train_classifier.py`, флаг `--classifier forest`).
- **Обучение:** только **синтетика** (`scripts/train_classifier.py`): 225 сцен на обучение, 75 на проверку. Проверка — на других сценах, а не на соседних окнах тех же. В сценах есть разный рост, скорость, длительность падения 0,5–1,2 с, дрожание точек, пропуски кадров, наклон к полу и приседание.
- **Качество на синтетической проверке** (`eval/classifier_metrics.json`):

  | | Macro-F1 | Ложные «падает» | Пропущенные окна падения |
  | --- | --- | --- | --- |
  | Random Forest | 0,958 | 0 | 2 из 109 |
  | Правила | 0,894 | 0 | 21 из 109 |

  Это проверка того, что признаки и код работают. **Это не оценка на людях.** Реальная оценка — после записей SCRUM-87.
- **Где ошибается:**
  - Медленная ходьба на месте принимается за «стоит».
  - Правила пропускают часть окон медленного падения (около 1,2 с) и называют глубокий наклон «лежит».
  - Синтетический скелет идеален по пропорциям, поэтому реальная поза от YOLO будет шумнее.
- **Ограничения и этика:** только скелеты, лица не используются. Не медицинское изделие: решение принимает оператор.
- **Владелец:** роль ML.
