# ADR-0003: Роли захватываются коммитом закрытой задачи

- **Статус:** принято
- **Дата:** 2026-11-11
- **Задача:** SCRUM-4

## Контекст

Роли в команде заранее не распределены. Правило руководителя: кто первым выполнил задачу роли, тот её и забирает.

## Решение

- Задача закрывается строкой `Task-Done: SCRUM-123` в сообщении коммита.
- Workflow `claim-role` после пуша в `main` сверяет ключ с `.github/roles/task_roles.json` и закрепляет свободную роль за автором.
- Он же пересобирает `ROLES.md` и `.github/CODEOWNERS`: владелец роли автоматически становится обязательным ревьюером своих папок.

## Последствия

GitHub должен узнавать автора коммита: почта в `git config user.email` должна совпадать с почтой аккаунта (или noreply-адресом). Если `main` защищена правилами, боту нужен токен с правом обхода — см. `docs/process.md`, раздел 3.
