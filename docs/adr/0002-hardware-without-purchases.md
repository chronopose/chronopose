# ADR-0002: Железо MVP — только то, что есть

- **Статус:** принято
- **Дата:** 2026-11-11
- **Задача:** SCRUM-6

## Контекст

Бюджета нет. В наличии — Android-смартфоны команды и одна ESP32 (Wi-Fi + Bluetooth). MVP нужен к 1 декабря 2026.

## Решение

- Камера — смартфон с приложением IP Webcam (MJPEG-поток по HTTP).
- Носимый датчик (IMU) — второй смартфон на поясе, приложение phyphox с удалённым доступом; мост `src/iot/phone_imu_bridge.py` публикует данные в MQTT.
- Исполнитель — ESP32: подписка на `cps/alerts`, светодиод.
- Сервер — ноутбук команды, Mosquitto, Python.

## Варианты, которые отвергли

| Вариант | Почему нет |
| --- | --- |
| Отдельные IP-камеры | Покупка |
| IMU-модуль MPU-6050 на ESP32 | Покупка и пайка; смартфон даёт тот же акселерометр и гироскоп |
| Облачный сервер | Задержка и зависимость от интернета на демо |

## Последствия

Частота IMU зависит от телефона (обычно 50–100 Гц) — фиксируем фактическую в отчёте. Все устройства в одной сети Wi-Fi; на демо — точка доступа с телефона и запасной прогон по записи (см. `docs/process.md`).
