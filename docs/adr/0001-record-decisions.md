# ADR-0001: Записываем архитектурные решения

- **Статус:** принято
- **Дата:** 2026-11-11
- **Задача:** SCRUM-3

## Контекст

Команда из пяти человек, роли захватываются по мере работы, состав зон может меняться. Через месяц никто не вспомнит, почему выбран, например, ByteTrack, а не BoT-SORT.

## Решение

Каждое решение, которое меняет архитектуру, контракт между модулями (топики MQTT, формат события, API) или выбор модели, оформляем коротким ADR в `docs/adr/` по шаблону `0000-template.md`. ADR входит в тот же PR, что и код. Принятые ADR не редактируем — заменяем новым.

## Последствия

Плюс пять минут на PR. Взамен — история решений для отчёта НИР и защиты 12.12.
