# MVP к 1 декабря 2026

**Сценарий:** человек с телефоном на поясе идёт перед телефоном-камерой и имитирует падение на мат. Система видит позу, классифицирует действие, сверяет с датчиком, пишет текст на демо-странице, а ESP32 мигает светодиодом.

## Железо — без закупок

| Устройство | Роль в системе | Как |
| --- | --- | --- |
| Android-телефон №1 | Камера | Приложение IP Webcam → поток `http://<ip>:8080/video` |
| Android-телефон №2 | Носимый IMU на поясе | phyphox → удалённый доступ → `src/iot/phone_imu_bridge.py` |
| ESP32 (Wi-Fi + Bluetooth) | Исполнитель | `firmware/esp32_alarm` — светодиод по топику `cps/alerts` |
| Ноутбук команды | Сервер | Python, YOLO-pose на CPU или GPU, Mosquitto |

Все устройства в одной сети Wi-Fi (можно раздать с телефона). Названия приложений и адреса проверьте на своих телефонах.

## Критерий готовности MVP

- [ ] Один прогон «падение → оповещение» проходит от начала до конца без ручных действий.
- [ ] Текст оповещения появляется на демо-странице меньше чем через 4 секунды после падения.
- [ ] ESP32 мигает по каждому подтверждённому событию.
- [ ] Без телефона-IMU система работает по видео и пишет «подтверждения датчика нет».
- [ ] Видео прогона записано.
