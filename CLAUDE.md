# Правила проекта для ИИ-ассистентов

Проект: студенческий НИП, детекция позы и классификация поведения в киберфизической системе. MVP — к 01.12.2026, показ — 12.12.2026.

## Ограничения

- Железо: только Android-смартфоны и одна ESP32. Не предлагать покупки (ADR-0002).
- Приватность: обрабатываем скелеты, не храним лица; не делать распознавание личности.
- Не добавлять ИИ-ассистента в авторы или соавторы коммитов, PR и релизов (без строк `Co-Authored-By`).

## Как устроен код

- `src/events/engine.py` — конечный автомат событий; `src/alerts/generator.py` — шаблонный текст оповещения: в тексте только поля события, без выдумок.
- `src/replay.py` — прогон по записи JSONL; `scripts/eval_gate.py` — гейт качества против `eval/baseline.json`.
- Топики MQTT: `cps/imu/{device}/telemetry`, `cps/alerts`, `cps/actuators/{id}/ack|status`. Изменение топика — только с ADR.

## Перед тем как предложить PR

```bash
ruff check .
pytest -q
python scripts/eval_gate.py
```

Все три должны быть зелёными. `eval/baseline.json` не обновлять без явной просьбы человека.

## Стиль

Python 3.11, ruff (длина строки 120), комментарии и документация — по-русски, коротко. Сообщение коммита — в повелительном наклонении; закрытие задачи — строка `Task-Done: SCRUM-123`.
